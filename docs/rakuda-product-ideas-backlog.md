| **盤面** | セルもリスト内絵文字で埋める（ひらがな常設と同型の pickup 生成） |
| **募集で絵文字作成** | **第1弾は常設のみ**（作成フォームに 😀 を広げない — 依頼時まで） |

### 位置づけ

| 項目 | 方針 |
|------|------|
| 入口 | `https://rakuda.coffee/` トップ（`SeatSelection`）に **「9×9数字」** ボタン1つ（リバーシ・スライドパズル同列） |
| 文言 | 見出し「9×9数字パズル」＋一言「1〜9を並べる」（ルールは遊びながら） |
| 世界観 | ひとり・静か・煽らない。タイマー競争・連勝ランキングなし |
| 端末 | 3GB級想定。生成は軽量・盤面DOMはシンプル |
| 横展開 | ことば/ひと言/リバーシ利用者が **隣の席** として触れる |

### リバーシ同様 — 難易度別

| 難易度 | 豆案（初期ヒント数・生成） | 想定 |
|--------|---------------------------|------|
| **やさしい** | 与件（最初の数字）多め・解法手順が単純 | 初めて・子ども・らくださん学習用 |
| **ふつう** | 標準的な初級〜中級 | 慣れてきた人 |
| **むずかしい** | 与件少なめ | 上級（後回しでも可） |

難易度は **メニューで選んでから開始**（リバーシ CPU 難易度選択に近い UX）。

### ヒント — 要るか？

**やさしい／初回だけは「あるとよい」**（らくださん自身の学習にも効く）。

| 種類 | 方針 |
|------|------|
| **初回チュートリアル** | 1画面。「行・列・3×3ブロックに1〜9が1つずつ」「計算不要」 |
| **矛盾ハイライト** | 同じ行/列/ブロックで数字が重なったら **優しく色付け**（自動・常時ONでも可） |
| **1マスヒント** | **任意ボタン**。「このマスは ○」（回数制限 or やさしいだけ無制限）— 押し付けない |
| **全面解答** | 付けない（学習目的と世界観のため） |

むずかしいではヒント弱め or なしでもよい。
