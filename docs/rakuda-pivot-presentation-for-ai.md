**旧モデルの問題（らくださんの体感）**

- 広告も収益も **中途半端**（未接続でゼロ）
- 480円は **子どもには関係ない話** — 大人向け扉がチャットに届かない
- 案内・ピン留め・特商法までやっても **本番有料契約ゼロ**
- 「タダで遊ぶのが当たり前」層と、**自分だけが身銭を切っている** 現実のギャップ

## 5. 新構想（2026-06-08 対話で整理・**未実装**）

### 5.1 コア方針

| 項目 | 新方針 |
|------|--------|
| **サイト内広告** | **全面廃止**（全利用者・全ゲート） |
| **収益** | **寄付のみ**（応援サブスク ＋ 特別寄付） |
| **応援サブスク** | **月150円以上・金額は利用者が選ぶ**（480円廃止） |
| **特別寄付** | 100円以上・自由金額（既存の考え方を継続） |
| **特典** | **金額に応じた優遇なし**。10万円も150円も遊び方は同じ |
| **唯一の例外** | **名前・絵文字の緑** — 「払った証」ではなく **応援の意思表示** |
| **コスト開示** | **大人だけ**に見せる（設定・大人向け扉） |

### 5.2 開示する数字（案）

```
【運営の数字 — 大人の方へ】

・28日の利用者：397人（目安）
・今月の応援：○人 / ¥○
・毎月の固定費（目安）：
    サーバー（Firebase・Hosting 等）
    ドメイン（rakuda.coffee）
    Cursor Pro+（開発・改善）  ← らくださんが明示的に載せたい
    合計 約 ¥○ / 月
・不足分 … らくだが自己負担している

子どもには関係ありません。
無理に払う必要はありません。
```

**意図**：煽らない。**事実の鏡**。「見て見ぬふりをして負担を誰か任せにしている大人のマインドに一石を投じたい」— らくださんの言葉。

### 5.3 成功の定義（らくださん）

| 段階 | 定義 |
|------|------|
| **北極星** | 月 **¥1,000,000** が3〜6ヶ月連続安定（10人×特別寄付10万 ＝ 成功イメージ） |
| **中期** | 利用者増 → 噂 → **関係企業・自治体が無視できない実体** |
| **短期** | 応援 **1人目**（本番・有料） |

### 5.4 らくださんの本音（要約）

- お金のことで **ヤケ** がある。自分でも **無茶かも** と思っている
- それでも **中途半端な配信・中途半端な判断** の方が気持ち悪い
- 生活費に届かないなら、**気持ちよく一貫した方** を選びたい
- **何も売りがないサイト** より **はっきりした特徴** を持ちたい
- 寄付が足りない分を **自分で払っている現実** を、払う気のある大人に見せたい
- 子どもには関係ない — **大人の責任**

## 6. 豆（開発AI・Cursor Pro+）の見解 — 参考情報

らくださんは豆の意見を **厳しいけど正しい** と感じている。他AIは同意・反論どちらでもよいが、以下を前提に議論してほしい。

| 論点 | 豆の立場 |
|------|----------|
| **無茶か** | 生活費を寄付だけで **今すぐ** 賄うのは厳しい。**一貫性の選択** としてはらくだらしい |
| **150円/月** | 寄付入口として適切。**固定150より「150以上・自由」** が構想と一致 |
| **広告全廃** | 世界観◎。収益面では **AU×広告** の可能性も捨てる — 覚悟の問題 |
| **特典なし** | 世界観◎。転換率は下がる — **倫理とCVRのトレードオフ** を指摘してほしい |
| **実装** | 構想確定まで **動かない**（2026-06-08 時点で一度入れたUIは差し戻し済み） |

## 7. やらないこと（他AIも提案しないでほしい）

- ランキング煽り・課金競争・ガチャ大量
- 金額 tiers で体験を変える（Pay-to-win）
- 子ども向け画面へのお金の話・ guilt 煽り
- 子ども向けに広告を増やすだけの施策
- URL変更・別アプリ分割で入口を散らばらせる
- 世界観に合わないインフルエンサー大量投入
- 緑の無料配布の再開（感謝パス乱発）

## 9. 他AIへの質問（詳細版）

### A. 事業判断

1. **新構想（広告なし・寄付のみ・コスト開示・特典なし）** は、397 AU・19分エンゲージ・収益ゼロの条件下で、**続けるに足る判断** か？
2. らくださん自身が感じる **「無茶」** のうち、**避けられないリスク** と **避けるべき無茶** を分けて説明してほしい。
3. **旧モデル（広告＋480）を完全に捨てる** こと vs **移行期だけ残す** こと — どちらが合理的か？ 移行期があるなら **最長何ヶ月** まで？

### B. 収益を軌道に乗せる

4. **150円/月以上・自由金額** の応援サブスク — 転換率・Stripe手数料・文案の観点で **改善案** は？
5. **特別寄付10万×100人** という北極星 — 非現実的な部分と、**そこから逆算できる現実的マイルストーン** を提案してほしい。
6. サイト内収益が動く前に、**YouTube・TikTok・法人・自治体** のどれを **第2の柱** にすべきか？ 世界観制約付きで。
7. **「実体成長」（噂・無視できない存在）」** を最短で進める施策 3つ — 煽りなしで。

### C. 「大人への一石」設計

8. コスト開示 UI の **倫理**（guilt vs 透明性）と **効果**（転換に効くか）を評価してほしい。
9. 子ども向け配信・チャットと **大人向け寄付導線** を分離する **ベストプラクティス** は？
10. 「金額で優遇しない」方針を **Stripe・特商法・利用規約** 上どう書くのがよいか？

### D. 次の展開（30日・90日）

11. 構想確定後 **最初の2週間** にやるべきこと（コード・法務・告知・配信）の優先順位。
12. **成功/KPI** — 収益ゼロ期間中、何をもって「前に進いている」と判断すべきか？
13. らくださんの **メンタル・体力（一人運営）** を踏まえた **持続可能なペース** の提案。
