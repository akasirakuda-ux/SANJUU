**入口（公式）**: https://www.tiktok.com/tiktokstudio  
（別名 **TikTok Studio**。`@akasirakuda` と**同じログイン**）

| PCでできること | 画面の目安 |
|----------------|------------|
| 残高・推定報酬の確認 | **収益化** |

| 参加できる収益プログラムの一覧 | **収益化** → おすすめ／有効なプログラム |

**注意（PCだけだと詰まることがある）**

- **身分証の撮影**だけ、アプリに誘導されることがある → そのときだけスマホで続き（PCにWebカメラがあればそのまま完了することもある）
- **LIVE ギフト ON** は配信準備画面の確認が必要なため、PCに項目が無ければスマホ **設定 → クリエイターツール → LIVE** で最終確認

**PCのこの順**: ログイン → **収益化** → **本人確認**（未完了なら）→ **振込先** → （必要なら）スマホで LIVE ギフト ON

**収益化トップに「本人確認」が無いとき（2026-06-04 画面）**

- 一覧の **有効なプログラム**（動画ギフト / **LIVE報酬** / サブスク）の **「見る」** の中に、**出金・支払い設定・本人確認** が出ることが多い
- **あなたにおすすめ**（Creator Rewards 等）が **対象外** でも、**LIVE報酬は有効**なら LIVE 側だけで換金準備できる（Creator Rewards は別ルート）
- それでも無い → **残高** タブ、またはスマホ **プロフィール → ≡ → 残高**
- **LIVE報酬の「見る」→ QRコード**「スキャンしてTikTokアプリを開いてください」→ **本人確認・支払い設定はスマホ必須**（PCは状況確認まで）
- **QR後のアプリ画面（TikTok Studio）**: 推定報酬 **$1.16** 表示。**LIVE報酬** カードの **「詳細を見る」** が換金・本人確認の入口。**TikTok Shop（参加）** は物販用で今回の LIVE 換金とは別
- **LIVE報酬 → ギフトハブ**: **視聴者向けギフトのカタログ**（レオナルド王の伝説等）＋ **LIVEを開始**。**本人確認・銀行口座ではない**
- **換金・本人確認の入口（日本アプリ）**: 「残高」が無いときは **ポケット**（英 Balance / Wallet）。経路A **≡ → 設定とプライバシー → ポケット → LIVE報酬**。経路B **≡ → クリエイターツール → 収益化 → 支払い設定**

## 手順（スマホ・この順で）

### 1. クリエイターアカウントになっているか

1. TikTok → **プロフィール** → **≡** → **設定とプライバシー**
2. **アカウント管理** → **アカウントの切り替え**（または **クリエイターツール** が見えるか）
3. **クリエイターアカウント** になっていなければ切り替え

### 2. 本人確認（KYC）— 最優先

1. **設定とプライバシー** → **クリエイターツール**（または **残高** / **TikTok Studio**）
2. **本人確認** / **Verify identity** を開く
3. 運転免許証・マイナンバーカード・パスポートのいずれかで完了
4. 審査：**数時間〜数日**（ここが未完了だと換金不可）

**らくださん（2026-06-04）**: **本人確認済み**（運転免許証・「本人確認が完了しました」画面）。**ポケット → コンテンツ報酬**: 獲得済み **USD 288.95**、**換金する** 表示まで到達 → **収益設定は実質完了**（出金は必要なときだけ）
- **換金テスト成功**: **USD 100** 申請済み（手数料 USD 3・銀行末尾87・着金待ち 3〜7営業日）。**TikTok LIVE 換金レール完了**

### 3. 振込先（換金口）

同じ **残高** / **収益化** エリアから：

| 方法 | らくだ向けメモ |
|------|----------------|
| **国内銀行口座** | いちばん分かりやすい。**口座名義＝本人確認名** |
| **PayPal** | 使うなら JPY 受取設定を確認 |

- 支店・口座番号を間違えない
- 登録後、**テスト換金は不要**（最低額に達してからでよい）

### 4. LIVE ギフトを ON

1. **設定とプライバシー** → **クリエイターツール** → **LIVE** 関連
2. **LIVE ギフト** / **Receive gifts during LIVE** を **ON**
3. 次回 LIVE 開始前に、配信準備画面でも **ギフト** が有効か確認

### 5. （任意）LIVE サブスクリプション

- 日本向けに提供あり（バッジ・サブスク限定チャット等）
- **煽らず**「続けて応援したい人向け」程度でよい（世界観）
- メニューに出ていれば **有効化** → 価格・特典はアプリの案内どおり

### 6. 配信前の確認（毎回30秒）

- [ ] プロフィールリンク **rakuda.coffee** が生きている
- [ ] LIVE ギフト ON
- [ ] 子ども向けの場として **ギフト煽り・ランキング煽りはしない**（既存の配信方針どおり）

### 7. 換金（ダイヤが溜まってから）

1. **プロフィール** → **≡** → **残高**（または **クリエイターツール** → **残高**）
2. **ダイヤモンド** / **収益** の残高を確認
3. **出金** / **Withdraw** — **最低額**はアプリ表示どおり（為替・時期で変わる）
4. 申請 → 着金まで **数日〜営業日**（初回は本人確認待ちと重なることがある）
