## らくださん要件（2026-05-31）

### ルール（上海ソリティアと同型）

| 項目 | 内容 |
|------|------|
| **基本** | 同じ絵柄2枚を取る。取ったら下の牌が露出 |
| **自由な牌** | 上に何も乗っていない **かつ** 左右どちらかが空いている |
| **標準枚数** | **144枚**・**亀（タートル）** 配置・**5層**（上海の定番） |
| **絵柄** | ひらがな・カタカナ・漢字・数字・アルファベット・絵文字（4枚組＋特殊牌は後述） |

### 難易度（確定：B — 48 / 96 / 144）

| 難易度 | 枚数 | レイアウト |
|--------|------|------------|
| **やさしい** | **48** | 10種の山から外側を削った形 |
| **ふつう** | **96** | 同上（中間） |
| **むずかしい** | **144** | 同上（フル） |

**牌山の形（10種・毎局ランダム）：** 亀 / ピラミッド / ダイヤ / 十字 / 城 / 双塔 / 階段 / 柱 / 扇 / 門

### マッチルール（確定）

- **同じ記号だけ** がペア（花・季節の「種類マッチ」は使わない — シンプル）

### 操作（確定）

| 機能 | 仕様 |
|------|------|
| **ヒント** | 次の一手を1組表示。**1局3回まで** |
| **一手戻す** | 直前の1手だけ取り消し。**1局5回まで**（豆案・下記） |
| **中止** | 確認 → 席選択（らくだ珈琲）へ |

一手戻すの回数：ヒントより少し多めの **5回** を推奨（誤タップ救済）。無制限も可能だが、ヒント＋戻しの繰り返しで局が短くなりすぎるため制限ありを採用予定。

### スマホUI（必須）

- **亀の山を全体表示**：1画面に収まらない分は **縦スクロール** ＋ **ピンチ／ボタンで縮小**（牌は絵文字・大きめタップ領域）
- **3GB**：画像牌なし・層の DOM/CSS は浅く・配信モード連携

### 操作

| 機能 | 内容 |
|------|------|
| **ヒント** | **次の一手** — 取れるペアの2枚を短くハイライト（回数制限あり案：3回/局） |
| **中止** | 確認ダイアログ → **らくだハブ（席選択）** へ（進行中の局は破棄） |

### リリース順（確定）

1. **ひとり用**（難易度3段・ヒント・一手戻す・中止・山全体表示）
2. **二十人共同**は後（上限20・満室分散はひと言探し側で済）

### 二十人共同（別フェーズ）

- 上限 **20人**・満室分散はひと言探しと共通（実装済み）
- ペア探しの共同同期は段階2以降
