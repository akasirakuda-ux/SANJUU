## 豆の行動ルール（このメモ以降）

- **完了の定義**: らくださんが「できた」と言う、または依頼どおりの検証結果をらくださんが送るまで未完

- ログイン失敗時: 文言変更ではなく **auth・Cookie・authDomain・オリジン** を疑う
- 謝罪は短く、事実を認め、先に進めない
